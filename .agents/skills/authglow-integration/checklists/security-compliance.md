# Security and Compliance Checklist

Mark each applicable control `[x]` only when the implementation or test provides evidence.

## Client and flow

- [ ] Client type is explicitly classified as public or confidential.
- [ ] Flow matches the client type and user/service requirement.
- [ ] Passwords are never collected by the integrating application.
- [ ] `/api/token` is not used by an external client.
- [ ] PKCE S256 is used for public clients.
- [ ] Client secret/private key is absent from browser/mobile bundles.

## Authorization request

- [ ] `state` is fresh, unpredictable, bound to the login transaction, and single-use.
- [ ] `nonce` is fresh and stored with the transaction for OIDC.
- [ ] `code_verifier` is generated by a CSPRNG and is not logged.
- [ ] `redirect_uri` is an exact registered URI.
- [ ] Requested scopes are minimal and documented.

## Callback and tokens

- [ ] Callback origin/path is checked against the expected redirect URI.
- [ ] OAuth errors are handled before token exchange.
- [ ] `state` is compared before accepting the code.
- [ ] Authorization code is exchanged only once.
- [ ] ID token signature is validated with JWKS.
- [ ] ID token `iss`, `aud`, `exp`, `iat`, and `nonce` are validated.
- [ ] Access-token audience and scopes are enforced by the resource server.
- [ ] Tokens are not stored in `localStorage` or exposed in URLs/logs.

## Session and lifecycle

- [ ] Browser session uses secure, httpOnly cookies where applicable.
- [ ] Refresh tokens are rotated and old tokens are discarded.
- [ ] Refresh-token reuse is rejected and handled as a security event.
- [ ] Logout clears the application session.
- [ ] OIDC logout validates post-logout redirect URIs.
- [ ] CSRF protection is present for cookie-authenticated state-changing requests.

## Evidence

- [ ] Unit tests cover state/nonce/PKCE failure cases.
- [ ] Integration test covers login, callback, exchange, session, and logout.
- [ ] Build, lint, and typecheck pass.
- [ ] No secrets appear in source, logs, screenshots, or generated artifacts.
