# AuthGlow Testing Guide

This guide provides instructions for manually testing the core features of AuthGlow.

---

## 1. Initial Setup

Before you begin, ensure you have completed the setup steps in the main `README.md`:
1.  Cloned the repository.
2.  Created and activated a virtual environment.
3.  Installed dependencies with `pip install -r requirements.txt`.
4.  Created and configured your `.env` file.
5.  Started the application with `python main.py`.

You will also need a tool for making API requests, such as `curl` or a graphical client like Postman or Insomnia.

---

## 2. Core Authentication

### Test 1: Get an Access Token

The most direct way to authenticate is to exchange user credentials for a JWT access token.

**Request:**
```bash
curl -X POST http://localhost:8000/api/token \
  -H "Content-Type: application/x-www-form-urlencoded" \
  -d "username=YOUR_ADMIN_EMAIL" \
  -d "password=YOUR_ADMIN_PASSWORD"
```

**Expected Response:**
You should receive an `access_token` and a `refresh_token`.
```json
{
  "access_token": "eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9...",
  "token_type": "bearer",
  "expires_in": 1800,
  "refresh_token": "eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9...",
  "scope": "read write admin"
}
```
**Save the `access_token` for use in subsequent authenticated requests.**

### Test 2: Access a Protected Route

Use the `access_token` as a Bearer token to access a protected endpoint.

**Request:**
```bash
curl http://localhost:8000/api/profile/me \
  -H "Authorization: Bearer YOUR_ACCESS_TOKEN"
```

**Expected Response:**
You should receive the profile information for the authenticated user.
```json
{
  "id": "...",
  "email": "YOUR_ADMIN_EMAIL",
  "is_active": true,
  ...
}
```

## 3. Admin Portal & User Management

### Test 3: Invite a New User

Use your admin `access_token` to invite a new user to the application.

**Request:**
```bash
curl -X POST http://localhost:8000/api/users/invite \
  -H "Authorization: Bearer YOUR_ADMIN_TOKEN" \
  -H "Content-Type: application/json" \
  -d 
  {
    "email": "new.user@example.com",
    "first_name": "Test",
    "last_name": "User",
    "scopes": ["read"]
  }
```

**Expected Response:**
A new user object is returned. If you configured `EMAIL_BACKEND=file_storage`, a welcome email will be saved in `data/users/emails/`.

### Test 4: Explore the Admin Portal

1.  Navigate to `http://localhost:8000/admin` in your browser.
2.  You will be prompted to log in. Use your admin credentials.
3.  Explore the different sections:
    *   **Dashboard:** View user statistics.
    *   **Users:** See the new user you just invited.
    *   **Audit Logs:** Review the logs generated by your recent API calls and logins.
    *   **API Playground:** Use this tool to interactively test the different OAuth2 and API flows.

## 4. Passkeys (WebAuthn)

### Test 5: Register a Passkey

1.  Log in to the application as a regular or admin user.
2.  Navigate to `http://localhost:8000/passkeys`.
3.  Click **"Add a New Passkey"**.
4.  Follow the browser/OS prompts to register a passkey (e.g., using your fingerprint, face, or a security key).
5.  Give the new passkey a descriptive name.

### Test 6: Authenticate with a Passkey

1.  Log out of the application.
2.  Navigate to the login page.
3.  Enter the email address of the user who just registered a passkey.
4.  Click **"Sign in with Passkey"**.
5.  Follow the prompts to authenticate with the passkey you just created.

**Expected Result:** You should be logged in successfully without needing a password.

---

## 5. Multi-Factor Authentication (MFA)

### Test 7: Enable MFA

1.  Log in to the application.
2.  Navigate to the profile or security settings page where MFA setup is located.
3.  Initiate MFA setup. The API will return a `secret`, a `qr_code`, and a list of `backup_codes`.
4.  **Scan the QR code** with an authenticator app (like Google Authenticator or Authy).
5.  **Save the backup codes** in a secure location.
6.  Enter the 6-digit code from your authenticator app to verify and enable MFA.

### Test 8: Log in with MFA

1.  Log out and attempt to log in again with your username and password.
2.  After submitting your credentials, you should be prompted to enter your 6-digit MFA code.
3.  Enter the code from your authenticator app to complete the login.
