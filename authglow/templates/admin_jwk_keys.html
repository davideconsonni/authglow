JWK Key Management

How key rotation works: The active key signs all new tokens. Verifying keys are used to validate tokens signed before the last rotation. Revoked keys are permanently rejected — tokens signed with them will fail verification. Auto-rotation happens every 90 days on app restart when JWT_AUTO_ROTATE=true.
