🧪 API Playground

Benvenuto nel playground dell'API! Quest'area è progettata per aiutarti a comprendere e testare in modo interattivo i flussi di autenticazione e autorizzazione di base supportati da AuthGlow.
Qui puoi simulare diversi scenari OAuth2, esplorare gli endpoint di OpenID Connect ed eseguire chiamate API autenticate per vedere come tutto si integra.

🔐 Codice di autorizzazione STANDARD

Il flusso più sicuro per le applicazioni web. Scambia un codice di autorizzazione con i token. Ulteriori informazioni

L'identificatore univoco per il tuo client OAuth2.
L'URL a cui l'utente viene reindirizzato dopo l'autorizzazione.
Gli ambiti di autorizzazione che stai richiedendo.
Un valore opaco per mantenere lo stato e prevenire attacchi CSRF.

🤖 Credenziali client M2M

Per l'autenticazione da macchina a macchina. Nessuna interazione dell'utente richiesta. Ulteriori informazioni

Mostra esempio cURL 
curl -X POST http://localhost:8000/oauth2/token \
  -d "grant_type=client_credentials" \
  -d "client_id=TUO_ID_CLIENTE" \
  -d "client_secret=TUO_SEGRETO_CLIENTE" \
  -d "scope=read write"

🔑 Concessione password TEST

Autenticazione diretta con nome utente/password. Fortemente sconsigliato in produzione. Ulteriori informazioni

Mostra esempio cURL 
curl -X POST http://localhost:8000/api/token \
  -d "grant_type=password" \
  -d "username=TUA_EMAIL" \
  -d "password=TUA_PASSWORD" \
  -d "scope=openid profile"

🔐 Autenticazione con chiave API M2M

Scambia una chiave API con un token di accesso. Crea chiavi API da Impostazioni → Chiavi API.

Mostra esempio cURL 
curl -X POST http://localhost:8000/api/token/api-key \
  -H "Authorization: Bearer TUA_CHIAVE_API"

🔄 Token di aggiornamento ROTAZIONE

Scambia il token di aggiornamento con un nuovo token di accesso. Include la rotazione automatica per una maggiore sicurezza. Ulteriori informazioni

Mostra esempio cURL 
curl -X POST http://localhost:8000/oauth2/token \
  -d "grant_type=refresh_token" \
  -d "refresh_token=TUO_TOKEN_DI_AGGIORNAMENTO" \
  -d "client_id=TUO_ID_CLIENTE"

🔍 Individuazione OpenID

Recupera la configurazione del provider OpenID Connect. Questo è il primo passo per la maggior parte delle integrazioni OIDC. Ulteriori informazioni

Mostra esempio cURL 
curl http://localhost:8000/.well-known/openid-configuration

👤 Endpoint UserInfo

Ottieni informazioni sull'utente utilizzando un token di accesso con l'ambito 'openid'. Ulteriori informazioni

Mostra esempio cURL 
curl http://localhost:8000/oauth2/userinfo \
  -H "Authorization: Bearer TUO_TOKEN_DI_ACCESSO"

🔓 Decodificatore token ID

Decodifica e ispeziona il token ID di OpenID Connect (JWT). Questo non verifica la firma. Ulteriori informazioni

🔐 Chiavi web JSON

Ottieni le chiavi pubbliche utilizzate per la verifica della firma JWT. I client utilizzano questo endpoint per convalidare i token ID. Ulteriori informazioni

Mostra esempio cURL 
curl http://localhost:8000/.well-known/jwks.json

🔬 Introspezione token

Esegui l'introspezione di un token per verificarne la validità e i metadati (RFC 7662). Utile per i server di risorse. Ulteriori informazioni

Mostra esempio cURL 
curl -X POST http://localhost:8000/oauth2/introspect \
  -d "token=TUO_TOKEN"

🚫 Revoca token

Revoca un token di accesso o di aggiornamento (RFC 7009). Essenziale per i logout e la sicurezza. Ulteriori informazioni

Mostra esempio cURL 
curl -X POST http://localhost:8000/oauth2/revoke \
  -d "token=TUO_TOKEN" \
  -d "token_type_hint=access_token"

📡 Chiamata API protetta con Token

Effettua una richiesta API autenticata con un token Bearer (Access Token) nell'intestazione di autorizzazione.

Mostra esempio cURL 
curl http://localhost:8000/api/profile/me \
  -H "Authorization: Bearer TUO_TOKEN_DI_ACCESSO"

🔑 Chiamata API protetta con Chiave API

Effettua una richiesta API M2M (machine-to-machine) autenticata direttamente con una Chiave API.

Mostra esempio cURL 
curl http://localhost:8000/api/admin/stats \
  -H "Authorization: Bearer TUA_CHIAVE_API"
