🧪 API Playground

Welcome to the API Playground! This area is designed to help you understand and interactively test the core authentication and authorization flows supported by AuthGlow.
Here you can simulate different OAuth2 scenarios, explore OpenID Connect endpoints, and make authenticated API calls to see how everything fits together.

🔐 Authorization Code STANDARD

The most secure flow for web applications. Exchanges an authorization code for tokens. Learn more

The unique identifier for your OAuth2 client.

🤖 Client Credentials M2M

For machine-to-machine authentication. No user interaction required. Learn more

Show cURL Example 
curl -X POST http://localhost:8000/oauth2/token \
  -d "grant_type=client_credentials" \
  -d "client_id=YOUR_CLIENT_ID" \
  -d "client_secret=YOUR_CLIENT_SECRET" \
  -d "scope=read write"

🔑 Password Grant TESTING

Direct username/password authentication. Strongly discouraged in production. Learn more

Show cURL Example 
curl -X POST http://localhost:8000/api/token \
  -d "grant_type=password" \
  -d "username=YOUR_EMAIL" \
  -d "password=YOUR_PASSWORD" \
  -d "scope=openid profile"

🔐 API Key for Token M2M

Exchange an API key for a short-lived access token. Create keys from Settings → API Keys.

Show cURL Example 
curl -X POST http://localhost:8000/api/token/api-key \
  -H "Authorization: Bearer YOUR_API_KEY"

🔄 Refresh Token ROTATION

Exchange a refresh token for a new access token. Includes automatic rotation for security. Learn more

Show cURL Example 
curl -X POST http://localhost:8000/oauth2/token \
  -d "grant_type=refresh_token" \
  -d "refresh_token=YOUR_REFRESH_TOKEN" \
  -d "client_id=YOUR_CLIENT_ID"

🔍 OpenID Discovery

Retrieve the OpenID Connect provider configuration. This is the first step for most OIDC integrations. Learn more

Show cURL Example 
curl http://localhost:8000/.well-known/openid-configuration

👤 UserInfo Endpoint

Get user information using an access token with the 'openid' scope. Learn more

Show cURL Example 
curl http://localhost:8000/oauth2/userinfo \
  -H "Authorization: Bearer YOUR_ACCESS_TOKEN"

🔓 ID Token Decoder

Decode and inspect an OpenID Connect ID Token (JWT). This does not verify the signature. Learn more

🔐 JSON Web Keys (JWKS)

Get the public keys used for JWT signature verification. Clients use this to validate ID Tokens. Learn more

Show cURL Example 
curl http://localhost:8000/.well-known/jwks.json

🔬 Token Introspection

Introspect a token to check its validity and metadata (RFC 7662). Useful for resource servers. Learn more

Show cURL Example 
curl -X POST http://localhost:8000/oauth2/introspect \
  -d "token=YOUR_TOKEN"

🚫 Token Revocation

Revoke an access or refresh token (RFC 7009). Essential for logouts and security. Learn more

Show cURL Example 
curl -X POST http://localhost:8000/oauth2/revoke \
  -d "token=YOUR_TOKEN" \
  -d "token_type_hint=access_token"

📡 Protected API Call (Token)

Make an authenticated API request with a Bearer (Access) Token in the Authorization header.

Show cURL Example 
curl http://localhost:8000/api/profile/me \
  -H "Authorization: Bearer YOUR_ACCESS_TOKEN"

🔑 Protected API Call (API Key)

Make a machine-to-machine (M2M) API request authenticated directly with an API Key.

Show cURL Example 
curl http://localhost:8000/api/admin/stats \
  -H "Authorization: Bearer YOUR_API_KEY"
