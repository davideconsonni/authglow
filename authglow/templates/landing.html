A lightweight, file-based Customer Identity & Access Management (CIAM) solution. Full OAuth 2.0 / OIDC provider with modern authentication features.

📚 Documentation ⭐ GitHub
⚠️ GENERATIVE AI-FIRST PROJECT

This is a complete software system designed and built entirely by AI agents (Claude Code with Claude 3.5 Sonnet and Gemini CLI with Gemini 2.5 Pro) without manual coding. Not intended for production use without thorough security review and testing.

🔐

OAuth 2.0 & OIDC

Fully compliant OAuth 2.0 and OpenID Connect provider. Secure your APIs and applications with industry standards.

🔑

Passkey Support

Passwordless authentication using FIDO2/WebAuthn. The future of authentication is here.

📱

Multi-Factor Auth

TOTP-based MFA with support for Google Authenticator, Authy, and other authenticator apps.

👥

RBAC

Role-Based Access Control with fine-grained permissions for your applications.

📄

File-Based Storage

No database required! All data stored in human-readable JSON files. Easy backups and migrations.

🛡️

Security First

Bcrypt password hashing, JWT tokens, rate limiting, audit logging, and automatic security notifications.

🎛️

Admin Dashboard

Web-based admin panel for managing users, OAuth clients, sessions, and viewing audit logs.

🔔

API Key Management

Issue and manage API keys for programmatic access with custom scopes and expiration.

✉️

Email Notifications

Customizable email templates for verification, password resets, and security alerts.
