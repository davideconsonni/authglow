Self-Hosted Authentication
Made Simple

A lightweight Customer Identity & Access Management (CIAM) solution powered by fsspec. Store locally or scale to cloud (AWS S3, GCS, Azure Blob). Full OAuth 2.0 / OIDC provider with modern authentication features.

📚 Documentation ⭐ GitHub

🤖 Generative AI-First Development

This project demonstrates co-thinking - a collaborative process where humans make all decisions and AI implements everything in code. Every line of code (~15,000+ lines) was generated through iterative dialogue with Claude Code (Claude 3.5 Sonnet) and Gemini CLI (Gemini 2.5 Pro), but all architectural decisions, requirements, and technical direction came from human guidance.

AuthGlow showcases the potential of human-led, AI-implemented development: humans as architects making decisions, AI as builders writing the code. Zero lines of code written manually, yet every choice guided by human intelligence.

Passkey Support

Passwordless authentication using FIDO2/WebAuthn. The future of authentication is here.

📱

Multi-Factor Auth

TOTP-based MFA with support for Google Authenticator, Authy, and other authenticator apps.

👥

RBAC

Role-Based Access Control with fine-grained permissions for your applications.

📄

Flexible Storage (fsspec)

No database required! Uses fsspec for storage abstraction. Store locally as JSON or scale to AWS S3, Google Cloud Storage, Azure Blob Storage.

Security First

Bcrypt password hashing, JWT tokens, rate limiting, audit logging, and automatic security notifications.

🎛️

Admin Dashboard

Web-based admin panel for managing users, OAuth clients, sessions, and viewing audit logs.

🔔

API Key Management
